Project | 2024

梦核教室

Dreamcore Classroom

🛠️ SketchUp / Adobe Substance 3D Stager / Dreamcore & Liminal Environment Design

以教室为基础空间，通过建模、材质、灯光和布景变化探索梦核与阈限空间氛围。

A classroom-based environment study that uses modeling, materials, lighting, and scenic changes to explore Dreamcore and liminal atmospheres.

Overview | 项目简介

项目先在 SketchUp 中建立教室及其基础空间关系，再使用 Adobe Substance 3D Stager 组织材质、灯光、镜头和渲染。熟悉的教室结构被保留为视觉锚点，同时通过不合常理的空间与表面变化制造介于日常和超现实之间的感受。

The project begins by establishing the classroom and its spatial relationships in SketchUp, then uses Adobe Substance 3D Stager to organize materials, lighting, cameras, and renders. The familiar room remains a visual anchor while improbable spatial and surface changes create a feeling between the everyday and the surreal.

Process | 过程

同一基础模型被发展为真实、云层、迪斯科和遗迹四类场景变体。对材质、光源、色彩和环境元素的连续调整，用于比较这些变量如何改变空间的可识别性、距离感和情绪，从而形成一组相互关联的梦核与阈限空间研究。

The same base model develops into real-world, cloud, discotheque, and relic variations. Repeated changes to materials, lighting, color, and environmental elements compare how those variables alter recognition, distance, and mood, producing a connected set of Dreamcore and liminal environment studies.
