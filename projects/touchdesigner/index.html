Project | 2024

宇宙叙事与投影映射原型 | Cosmic Storytelling and Projection Mapping Prototype

一个基于 TouchDesigner 的太空主题视觉叙事实验，围绕故事板、投影形状和节点网络，把行星、彗星、超新星与航天器素材组织成一段可展示的动态序列。 A TouchDesigner-based space narrative experiment that turns storyboards, projection shapes, and node networks into a presentable animated sequence built from planets, comets, supernovae, and spacecraft imagery.

Overview | 项目简介

中文

这个项目使用 TouchDesigner 搭建一个宇宙主题的视觉叙事原型。根据目录中的故事板、投影模板、最终导出视频以及多份 .toe 工程文件，可以看出它不是单张图像练习，而是一个从概念组织、镜头顺序到输出演示都较完整的流程实验。

页面中使用的素材覆盖行星、背景宇宙图像、彗星、超新星、航天器和节点网络截图，说明这个项目重点不只是视觉风格，也在测试如何将二维图像资源、合成逻辑和投影映射结合成一段连贯的空间叙事。

English

This project uses TouchDesigner to build a space-themed visual storytelling prototype. Based on the storyboard files, projection template, exported video, and multiple .toe files in the folder, the work reads as a process-driven study rather than a single image exercise.

The asset set spans planets, space backgrounds, comets, supernovae, spacecraft imagery, and node screenshots, which suggests that the project is not only about style but also about assembling 2D assets, compositing logic, and projection mapping into a coherent spatial sequence.

Process | 过程

中文

从现有文件命名可以看到一个比较清晰的工作流：先用 storyboard 和 projection_shape_storyboard_template 确定叙事节奏与投影形状，再通过多份 TouchDesigner 工程文件反复试验画面组织、节点连接和视觉效果，最后输出为 final.mp4 进行展示。

ExampleProtoStory、KantanTemplate、circuit、moon_black_hole 这些文件名也保留了探索痕迹，说明项目经历了多轮版本迭代。对作品集页面而言，这类过程材料很有价值，因为它们能证明作品不是只停留在结果图，而是包含方法、结构和测试。

English

The filenames point to a clear workflow: establish timing and projection shapes with the storyboard files, iterate on image sequencing and node structures through several TouchDesigner project files, and then export the result as final.mp4 for presentation.

Names such as ExampleProtoStory, KantanTemplate, circuit, and moon_black_hole preserve evidence of iteration. For a portfolio page, that matters because it shows a process with methods and tests rather than a single final frame.
